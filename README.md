# 功能开关追踪器（Feature Flag Tracker）

一个带版本、带逐步求值轨迹的功能开关系统。发布团队可以回答：**某个上下文下，开关为什么是 on / off / 某个变体？**

## 运行

需要 JDK 17+（仓库已带 Gradle Wrapper，无需预装 Gradle）。

```bash
./gradlew classes                     # 编译
./gradlew test                        # 全部测试
./gradlew run --args='--host 127.0.0.1 --port 5233'
# 浏览器打开 http://127.0.0.1:5233
```

数据默认持久化在 `data/flagtracker.json`（原子写入）。可用 `--data 路径` 或环境变量
`FFT_DATA=路径` 覆盖。首次启动会写入一个演示项目（两个开关、三个上下文、两条历史记录）。

## 能力

- **带版本的开关**：每次编辑发布一个不可变新版本；求值与历史记录都绑定具体版本。
- **按顺序求值的规则**：条件 AND 组合，规则自上而下第一条命中生效；支持固定值和百分比分流。
- **前置开关**：求值前置依赖并在轨迹中以内嵌子树呈现；整个依赖图拒绝环并给出环路径。
- **百分比分流（稳定公开算法）**：
  - 输入 `flagKey + "." + salt + "." + stableIdentity`
  - `bucket = SHA-256(输入)` 前 8 个十六进制字符按 uint32 取 `% 10000`（基点，0..9999）
  - 分桶输入**不含规则 id / 规则位置 / 版本**，所以只重排规则、分流条款（salt）不变时不会悄悄换桶；改 salt 才会换桶。
  - 权重用基点（10000=100%），端点为半开区间 `[start, end)`；权重和超过 10000 拒绝发布；未覆盖的尾部落到后续规则/默认值。
- **类型严格**：上下文里“字段缺失”和显式 `null` 分开记录；字符串与数字比较不隐式互转
  （`"3" != 3`，数字/字符串才能排序比较）。
- **批量快照隔离**：一次批量求值先冻结 `flagKey -> version` 快照，整条前置链都按该快照求值，
  期间发布新版本不会让结果混合；也可以显式传 `pinnedVersions` 重放某个旧快照。
- **敏感字段摘要**：被声明为敏感的字段，轨迹里不显示原值，只显示
  `HMAC-SHA256(SHA256("summary-v1|"+domainSecret), field+"="+canonical(value))` 的前 16 位十六进制。
  同一项目内相同输入摘要相同（可证明相等），不同项目（不同 domainSecret）之间无法关联。
- **历史与导入导出**：求值记录内嵌上下文快照和完整轨迹，重放始终按绑定版本；导出整个项目后
  再导入，salt/规则/版本逐字保留，分桶与轨迹顺序一致（`REPLACE` 为备份恢复；`MERGE` 合并外项目
  时重新生成 domainSecret 以隔离敏感摘要）。

## 网页

- 编辑规则顺序（拖拽）、拖动/输入百分比分流、增删条件与规则后发布新版本；
- 输入 JSON 上下文求值，展开/折叠求值树：读取字段、每条条件成败、分桶输入与桶值、前置依赖实际/期望值；
- 批量求值（所有开关，同一快照）；
- 选择两个版本，对一组保存上下文做影响对比；
- 保存上下文、保存求值记录、查看历史记录并重放；
- 一键导出/导入。

## HTTP API（摘要）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 整个项目 |
| POST | `/api/flags` | 新建开关 |
| POST | `/api/flags/{key}/versions` | 发布新版本（校验 + 环检测） |
| POST | `/api/flags/{key}/evaluate` | 单开关求值（可指定 `version`/`pinnedVersions`/`saveRecord`） |
| POST | `/api/evaluate-batch` | 一次快照的批量求值 |
| GET | `/api/flags/{key}/compare?a=&b=&contexts=` | 两版本对保存上下文的影响 |
| POST/DELETE | `/api/contexts[/{id}]` | 保存/删除上下文 |
| GET | `/api/records?flagKey=` | 求值记录 |
| POST | `/api/records/{id}/replay` | 按绑定版本重放 |
| GET | `/api/export` · POST `/api/import?mode=merge\|replace` | 导出/导入 |
