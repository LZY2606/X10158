# 功能开关追踪器（Feature Flag Tracker）

一个带**逐步求值轨迹**的功能开关系统：发布团队可以回答“为什么这个上下文得到了
on / off / 某个变体”。

## 运行

```bash
./gradlew classes                                   # 仅编译
./gradlew test                                       # 运行全部测试
./gradlew run --args='--host 127.0.0.1 --port 5233'  # 启动 Web
```

浏览器打开 <http://127.0.0.1:5233>，页面标题为「功能开关追踪器」。
首次启动会写入本地数据目录 `./data/feature-flags.json`（可用 `--data <目录>` 修改），
并自动创建一个演示项目、两个开关和三个保存的上下文。

## 求值模型

每个开关有不可变的**已发布版本**；草稿可以反复保存，发布才产生新版本。
对一个版本按以下顺序求值，轨迹记录每一步：

1. **前置开关**（按声明顺序）：用同一版本快照递归求值前置开关，观察其结果是否落在
   `anyOf` 中；不满足或前置缺失时直接给出 `gateServe`，不再评估规则。
2. **规则**（按页面中的顺序，首个命中生效）：
   - 每条规则有若干条件，AND 关系；首个失败条件即短路，轨迹标注成功/失败与原因。
   - 无分流条款时，条件全部满足就给出固定 `serve`。
   - 有分流条款时，进入百分比分桶；桶落在某条款区间给出该变体，否则给 `fallbackServe`。
3. **默认值**：没有任何规则命中时给出。

轨迹同时包含一份“读取字段台账”：每个被读到的字段标注 `missing` / `null` / `present`。

## 关键语义

- **缺失 ≠ null**：字段不存在记为 `missing`；存在但为 JSON `null` 记为 `null`。
  `eq null` 只匹配显式 null；`exists` 对显式 null 判定为存在。
- **严格类型比较**：字符串 `"100"` 不等于数字 `100`，数字比较、字符串操作都不做隐式转换；
  数字按数值比较（`100` 与 `100.0` 相等）。
- **稳定公开分桶算法**：MurmurHash3 x86 32-bit（seed 0），
  `bucket = hash_32("flagKey.salt.stableId") mod 10000`，权重以基点（0–10000）表示，
  区间为左闭右开。轨迹里完整展示分桶输入、salt、桶值和每条款的区间。
  重排规则但分流条款（规则 id/salt/权重）不变时，用户不会悄悄换桶。
- **前置依赖环**：发布时构建依赖图并拒绝环，错误中给出完整路径，如 `a -> b -> a`。
- **批量快照隔离**：一次批量求值开始时取得不可变版本快照；求值期间发布新版本不会让
  结果混合。也可以把整个批次钉在指定版本。
- **敏感字段**：在项目里声明（支持 `user.pii.*` 单层通配）。轨迹不显示原值，而显示
  `HMAC-SHA256(项目随机盐, 值)` 的 16 位摘要——同一项目内相同输入摘要相同（可证明相等），
  不同项目盐不同，摘要无法互相关联。敏感的稳定身份在分桶输入中同样只显示摘要。
- **历史绑定版本**：保存的求值记录钉住当时的版本；重放走该版本（含前置依赖版本），
  历史轨迹不会随后来的规则编辑改变。
- **导出 / 导入**：一个 JSON 包含项目（含盐）、开关全部版本、保存的上下文和历史记录。
  导入后分桶、敏感摘要、轨迹顺序保持一致（id 与盐保留）。

## Web 功能

- 「开关与版本」：编辑规则（增删条件、↑↓ 调整顺序）、拖动百分比滑块（基点）、
  管理前置依赖、保存草稿 / 发布新版本。
- 「求值」：粘贴 JSON 上下文或选用保存的上下文，选择开关与版本，展开可折叠的
  求值树（前置 → 规则 → 条件 → 分桶区间）与字段读取台账。
- 「版本对比」：选两个版本和一组保存的上下文，并排比较结果变化与两边轨迹。
- 「历史记录」：查看并按绑定版本重放。
- 顶部可导入 / 导出整包 JSON。

## 代码结构

- `Json.kt`：零依赖 JSON 模型 / 解析 / 序列化（数字保留词法，避免隐式转换）。
- `Hashing.kt`：MurmurHash3 与 HMAC-SHA256 摘要。
- `Model.kt` / `Codec.kt`：领域模型与 JSON 编解码。
- `ContextPath.kt`：点路径读取（区分缺失与 null）、敏感字段匹配。
- `Evaluator.kt`：求值与轨迹生成。
- `DependencyGraph.kt`：前置依赖环检测。
- `Store.kt`：本地原子持久化、版本快照、批量求值、历史重放、导入导出。
- `Server.kt` / `Main.kt`：JDK 内置 HTTP 服务与命令行入口。
- `src/main/resources/web/`：单页前端。

## 测试覆盖

`./gradlew test` 覆盖：缺失与 null、严格类型比较、端点百分比与分布、规则重排不换桶、
依赖环（含环路径）、并发发布下的批量快照隔离、敏感摘要的项目内一致与跨项目不可关联、
历史版本绑定重放、导出/导入后分桶与轨迹一致。
