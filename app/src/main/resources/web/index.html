这个开关为什么是 on / off / 某个变体？

从左侧选择一个开关，或新建一个。你可以：

  • 编辑条件规则的顺序，拖动设置百分比分流；
  • 在右上输入 JSON 上下文并求值，展开逐步轨迹：读了哪些字段、哪条条件成败、分桶输入与前置依赖；
  • 选择两个版本，对一组保存上下文做影响对比。

缺失字段与显式 null 区分处理；字符串与数字不会隐式互转。
